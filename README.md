# 🛍️ ShopEase - E-Commerce Store

ShopEase is a simple and responsive e-commerce web application developed using **HTML, CSS, JavaScript, Node.js, Express.js and MySQL**.

## ✨ Features

* 🛒 Product listing
* 🔍 Product search
* ➕ Add products to cart
* 🛍️ Shopping cart management
* 📦 Order placement
* 📋 Order history
* 🔐 User Registration and Login
* 📱 Responsive design
* 🗄️ MySQL database integration

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Node.js
* Express.js
* MySQL
* bcryptjs
* Express Session

## ▶️ How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Install dependencies:

```bash
npm install
```

4. Create the `ecommerce_db` database in MySQL.
5. Configure your MySQL password in `config/db.js`.
6. Start the server:

```bash
node server.js
```

7. Open in browser:

```text
http://localhost:5000
```
